# Court & Barbell

A 52-week tennis and powerbuilding planner (Oct 5, 2026 – Oct 3, 2027), built as an installable web app.
The year runs in four cycles, each ending with a Saturday mock meet: Cycle 1 · Fall (weeks 1–12), Cycle 2 · Winter (13–25),
Cycle 3 · League season (26–38, lighter lifting around USTA league play) and Cycle 4 · Summer (39–52).

**Open it:** https://dylankelzer.github.io/court-and-barbell/

## Add it to an iPhone
1. Open the link above in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. From then on, open it from the Home Screen icon. It runs full screen and works offline.

## Updating
A new version installs itself the next time the app opens with a connection. Close any other open copies (old Safari tabs) after an update.

## Where the data lives
Plans and logs are saved in the browser storage of the device that runs the app. Nothing is sent to a server.
The Home Screen app keeps its own copy, separate from Safari. Use **More → Save backup** to keep a copy or to move data to another phone, and **Import backup** to restore it.
